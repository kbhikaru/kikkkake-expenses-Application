精算書を作成する

対象月の承認済の申請を、支払者ごとの精算書（PDF）にまとめて Drive の月フォルダに保存します。各明細には「領収書」と「元データ（経費データの該当行）」へのリンクが入ります。同じ月を作り直すと上書きされます。

毎月の自動作成

オンにすると、毎月決まった日（設定 STATEMENT_AUTO_DAY）の朝6時台に前月分を自動で作成し、NOTIFY_EMAILS にメールでお知らせします。

月フォルダ・社員フォルダは申請時に自動で作成されます（設定 RECEIPT_SUBFOLDER_MODE＝月別+支払者）。

方式A：CSVで取り込む（おすすめ）

「承認済」の申請を freee会計の［取引の一覧・登録 → 取引のインポート］用CSVで出力します。

方式B：freee APIで直接登録

左で選んだ「まとめ方・対象月」で取引を登録し、証憑（精算書ごと＝精算書PDF／申請ごと＝領収書画像）を freee のファイルボックスに添付します。

freeeアプリの登録（初回のみ）
  1. freee アプリストアの「開発者向け」で新しいアプリを作成
  2. コールバックURLに下記を登録：
  3. 権限：取引・証憑・勘定科目・税区分・部門 の参照/更新
  4. 発行された Client ID / Secret を入力して保存
